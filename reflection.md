
## Learning and Benefits

Before this class, I was vaguely familiar with GitHub, but I had not used it. One thing I learned from the reading was there is a Project Board with Issue tracking. I really like how it is integrated within the desktop app itself, so you don't have to switch back and forth between GitHub and another project tracking software / file. Having task management will be really helpful for this class, as it will allow the teams to stay organized and divide up responsibility equally among the members. Also, a shared online repository for code will be very beneficial in general. This will allows us to make edits real time to the most current revision of the project. I couldn't imagine trying to pass code files back and forth for a project of this degree. 

## Challenge

I work for a small software company that has been around since the 70s. They are using Visual Studio (VS) / TFS as their source control manager. It has
been difficult for me to learn the nuances of Github. I understand the concepts, but the language is different between the two softwares. For example, a "commit" in
GitHub is called a "check-in" in VS.
